## 一、搜索引擎检索策略

### 1.1 核心搜索语法（日常最高频）

智能终端硬件情报搜索中，以下语法组合能覆盖 80% 的日常检索需求：

> **7 类产品形态**：平板 / 手机 / 智能手表 / AR-VR 眼镜 / 无线充 / 智能音箱 / 笔记本电脑
> **搜索窗口**：60 天（优先近 7 天，扩展到 60 天）

#### 基础限定

| 语法 | 用途 | 示例 |
|------|------|------|
| `site:` | 限定站点 | `Tandem OLED site:boe.com` — 只在京东方官网搜 |
| `filetype:pdf` | 限定文件类型 | `LPDDR5X datasheet filetype:pdf` — 找规格书 |
| `intitle:` | 标题含关键词 | `intitle:teardown iPad Pro` — 标题里就有"拆解" |
| `inurl:` | URL 含关键词 | `inurl:certification Wi-Fi 7 tablet` — URL 含认证相关 |
| `"..."` | 精确匹配 | `"silicon-carbon anode" battery` — 精确匹配词组 |
| `-` | 排除词 | `tablet -phone -smartphone` — 排除手机结果 |
| `*` | 通配 | `"*W fast charge" tablet` — 匹配 100W/65W 等 |
| `AROUND(N)` | 邻近搜索 | `battery AROUND(3) 100W` — 两词间距 3 词内 |

#### 组合实战

```
# 场景1：找竞品平板在 FCC 的电池信息
site:fccid.io "Galaxy Tab" battery mAh

# 场景2：找硅碳负极在智能终端上的应用论文/专利
("silicon-carbon" OR "Si/C") anode (tablet OR smartphone OR watch) filetype:pdf

# 场景3：排查竞品充电芯片方案（排除新闻稿）
("charging IC" OR "PMIC") teardown (tablet OR smartwatch) -press

# 场景4：找某型号的 3C 认证记录
site:cx.cnca.cn "型号" 平板

# 场景5：找供应链新闻但排除低质源
("BOE" OR "CSOT") "OLED" (tablet OR laptop) site:thelec.net OR site:etnews.com

# 场景6：找智能手表 3nm SoC 情报
("Snapdragon Wear" OR "3nm" OR "Exynos") smartwatch 2026

# 场景7：找 AR 眼镜光波导/Micro-OLED 情报
("waveguide" OR "Micro-OLED") AR glasses (XREAL OR "雷鸟") 2026

# 场景8：找 Qi2.2 无线充电认证情报
("Qi2.2" OR "Qi2" OR "25W") wireless charging (WPC OR magnetic) 2026

# 场景9：找智能音箱端侧 AI/NPU 情报
("on-device" OR "NPU" OR "Gemini Nano") smart speaker 2026

# 场景10：找 AI PC NPU TOPS 情报
("NPU" OR "TOPS" OR "Copilot+") laptop (Intel OR "Snapdragon X2" OR AMD) 2026
```

### 1.2 多语言搜索策略

平板硬件产业链跨多语区，同一关键词在不同语言圈返回的信息完全不同：

| 语言 | 关键信息类型 | 典型关键词 | 首选搜索引擎 |
|------|-------------|-----------|-------------|
| **英文** | 全球覆盖，芯片/标准/拆解/认证 | `teardown`, `datasheet`, `FCC ID`, `roadmap`, `smartwatch`, `AR glasses`, `Qi2`, `AI PC NPU TOPS` | Google |
| **中文** | 国内供应链、公众号首发、3C 认证、电商 | `拆解`, `入网`, `供应链`, `上市`, `智能手表`, `AR眼镜`, `无线充`, `智能音箱`, `AI PC` | 百度 + 微信搜一搜 |
| **韩文** | 三星/SK/乐金面板与存储、SDC 路线 | `태블릿` (平板), `스마트워치` (智能手表), `OLED 패널` (OLED 面板), `분해` (拆解), `무선충전` (无线充电) | Google + Naver |
| **日文** | JDI/夏普/索尼 CIS/ALPS 供应链 | `タブレット`, `スマートウォッチ` (智能手表), `ARグラス` (AR眼镜), `分解` (拆解), `パネル` (面板), `AI PC` | Google + Yahoo Japan |
| **德文** | 汽车/工业平板、材料认证（TÜV/CE） | `Tablet`, `Smartwatch`, `Zertifizierung` (认证), `Akkulaufzeit` (续航) | Google |

#### 多语言搜索 SOP

```
给定一个查询目标（如"竞品平板电池容量"）：
1. 英文先搜 → 取核心参数/型号 → 通常已覆盖 60% 信息
2. 中文补搜 → 电商参数页、3C 认证 → 补充国内特有渠道
3. 韩文精准搜 → 如果是三星面板/存储相关 → The Elec, ETNews
4. 日文精准搜 → 如果是 JDI/夏普/索尼器件 → PC Watch, 日经
5. 交叉验证：至少 2 个语种的独立信源确认同一参数
```

## 二、专利检索实操方法论

### 2.1 IPC 分类号速查表（平板硬件核心类）

原始文档提到"按 IPC+申请人做专利族去重"，但这需要先知道正确的 IPC 号。以下是平板硬件高频 IPC：

| IPC 分类号 | 覆盖范围 | 用法场景 |
|-----------|---------|---------|
| **G06F 1/16** | 结构细节、散热、铰链、折叠 | 平板整机结构、折叠屏铰链 |
| **G06F 3/041** | 触控面板 | 触控方案、压感 |
| **G06F 3/0354** | 手写笔/主动笔 | 笔协议、悬停、笔尖传感器 |
| **G06F 3/0488** | 触控手势/多指 | 触控交互 |
| **G09G 3/00** | 显示控制电路 | DDIC、TDDI 驱动方案 |
| **G09G 3/3225** | OLED 像素驱动 | Tandem OLED 驱动 |
| **G09G 3/36** | LCD 驱动 | LTPS/IGZO 驱动 |
| **H01M 4/38** | 硅基负极材料 | 硅碳负极电池 |
| **H01M 10/0525** | 锂聚合物电池 | 电芯结构 |
| **H01M 10/44** | 充电方法 | 快充协议 |
| **H02J 7/00** | 充电电路 | GaN 充电器方案 |
| **H04W 88/02** | 终端设备结构 | 天线布局 |
| **H05K 7/20** | 散热方案 | VC 均热板、石墨烯散热 |
| **H01Q 1/24** | 设备天线 | Wi-Fi/BT/UWB 天线 |
| **H04N 23/00** | 摄像头模块 | 平板影像方案 |
| **G02B 27/01** | 头戴显示 | XR/智能眼镜 |
| **H04R 1/02** | 扬声器定位 | 平板多声道方案 |

#### 检索命令示例

```
# USPTO 检索：苹果的平板散热专利
(CPC:G06F1/203 OR CPC:H05K7/2039) AND AN:"Apple Inc" AND (tablet OR iPad)

# WIPO PATENTSCOPE：找硅碳负极在便携设备上的专利
IC:H01M-4/38 AND (portable OR tablet OR smartphone)

# CNIPA（中国）：华为的主动笔专利
分类号:G06F3/0354 AND 申请人:华为

# Google Patents（免费且快，做初筛最好用）
(G06F1/16 OR H05K7/20) assignee:"Samsung" tablet after:2023
```

### 2.2 专利引证分析（追踪技术源头）

这是原始文档完全没提但极其有价值的技法：

> **核心逻辑**：A 公司引用 B 公司的专利 = A 用了 B 的技术路线 → 供应链线索

| 分析方向 | 方法 | 可获取的情报 |
|---------|------|-------------|
| **前向引证** | 谁引用了苹果的散热专利 | 哪些竞品/供应商在跟进这条技术路线 |
| **后向引证** | 苹果的电池专利引用了谁 | 苹果电池技术从哪里来的（收购/授权/借鉴） |
| **同族分析** | 同一专利在中/美/欧/PCT 的布局 | 竞品在哪些市场做专利防御，推测上市地区 |
| **引证突增** | 某专利近 2 年被引量暴增 | 该技术正在变成行业热点 |

#### 免费工具

| 工具 | URL | 能力 | 限制 |
|------|-----|------|------|
| **Google Patents** | patents.google.com | IPC 检索 + 引证图 + PDF 下载 | 无法批量导出 |
| **WIPO PATENTSCOPE** | patentscope.wipo.int | 跨库检索 + 同族分析 + 机器翻译 | 界面较慢 |
| **Espacenet** | worldwide.espacenet.com | EPO 数据库，引证可视化好 | 中文支持弱 |
| **Lens.org** | lens.org | 学术+专利引证交叉分析 | 数据更新有延迟 |
| **CNIPA PSS** | pss-system.cponline.cnipa.gov.cn | 中国专利全文 + 引证 | 需注册 |

### 2.3 专利检索 SOP

```
目标：判断"硅碳负极电池在平板上的竞争格局"
1. 定 IPC：H01M-4/38 (硅基负极) + G06F-1/16 (平板结构)
2. 初筛：Google Patents 搜 (H01M4/38) tablet，看数量趋势
3. 按申请人排序：看苹果/华为/三星/小米谁的专利最多
4. 引证分析：被引最多的专利是谁的→技术源头
5. 同族分析：中/美/欧/PCT 布局→判断商业化意图
6. 输出：技术趋势 + 竞品布局 + 我方空白区
```

## 三、认证数据库实操搜索

### 3.1 FCC ID 数据库

**FCC ID 结构**：`Grantee Code (3-5 chars) + Product Code (1-14 chars)`

| 厂商 | Grantee Code | 搜法 |
|------|-------------|------|
| Apple | BCG | `site:fccid.io BCG` 拉全部新品 |
| 三星 | A3L | `site:fccid.io A3L` (平板/手机/手表) |
| 华为 | QIS | `site:fccid.io QIS` |
| 小米 | 2AFZZ | `site:fccid.io 2AFZZ` (手机/平板/手表/音箱) |
| 联想 | O57 | `site:fccid.io O57` (平板/笔记本) |
| Google | A4R | `site:fccid.io A4R` (Pixel/Home Speaker) |
| Motorola | IFX | `site:fccid.io IFX` (手机/平板) |
| Meta | 2A5UW | `site:fccid.io 2A5UW` (AR-VR) |
| HP | B94 | `site:fccid.io B94` (笔记本) |
| Acer | E2C | `site:fccid.io E2C` (笔记本) |

#### 实操步骤

```
1. 切到 fccid.io（比官方 FCC 站快 10 倍）
2. 搜 Grantee Code → 按 Grant Date 倒序
3. 点开最新条目 → Internal Photos（内部照片：电池型号/电路板布局）
4. Test Report → SAR Report（天线位置）、RF Exposure（发射功率）
5. Label Info → 确认电池容量（mAh/Wh）、充电电压
```

### 3.2 中国 3C/CQC 认证

```
# 路径1：CQC 证书查询
cx.cnca.cn → 证书查询 → 输入企业名称（如"小米通讯"）→ 按发证日期倒序

# 路径2：全国认证认可信息公共服务平台
http://cx.cnca.cn/CertECloud/index/index/page

# 能拿到的信息
- 制造商/生产厂（供应链代工厂线索）
- 产品名称/型号（规格、充电器参数）
- 认证依据标准（如 GB 4943.1-2022 → 判断产品是 IT 类还是音视频类）
- 发证日期（上市前 1–3 个月）
```

### 3.3 Bluetooth SIG Launch Studio

```
# 搜法
launchstudio.bluetooth.com → Product Search → 输入竞品名称

# 可提取信息
- Declaration ID → 唯一标识
- Design → 蓝牙芯片/模块的详细型号（如 QCC5181、MT7921）
- Specification → 支持版本（5.3/5.4）、LE Audio 支持
- Listing Date → 蓝牙认证日期（早于产品上市 1–4 个月）

# 反向搜索：按芯片型号找客户
搜 "QCC5181" → 看哪些设备用了这颗芯片 → 竞品蓝牙方案
```

### 3.4 Wi-Fi Alliance Certification

```
# 路径
wi-fi.org → Product Finder → 输入设备名称

# 可提取信息
- Wi-Fi CERTIFIED 6/7 等版本
- WPA3 / Wi-Fi Easy Connect 支持
- 频段 (2.4/5/6 GHz) → 判断是否 Wi-Fi 7
- 认证日期 → 比上市早 1–3 个月

# 交叉验证
Wi-Fi 联盟 + FCC 的频段参数互证，两边都出现才算确认
```

### 3.5 其他认证快捷入口

## 四、问题驱动的快速搜索路径

原始文档是"渠道驱动"的（每天扫一圈信息源），但老板提问时走"问题驱动"的快速路径。

### 4.1 问题类型 → 搜索路径决策树

```
老板的提问
│
├── "XX 技术现在什么水平？"（技术调研型）
│   ├── 第一步：Google Scholar / arXiv 找综述论文（近 2 年）
│   ├── 第二步：Google Patents 看专利趋势（申请量曲线）
│   ├── 第三步：ISSCC/SID 会议论文看最新突破
│   └── 第四步：供应商官网看量产状态
│
├── "竞品 XX 用了什么方案？"（竞品拆解型）
│   ├── 第一步：iFixit / eWiseTech / 充电头网 搜拆解
│   ├── 第二步：FCC ID 看内部照片 + 用户手册
│   ├── 第三步：Bluetooth SIG / Wi-Fi 联盟反查芯片型号
│   ├── 第四步：供应链新闻交叉验证
│   └── 第五步：京东/天猫商品页确认规格
│
├── "XX 什么时候会普及？"（趋势预判型）
│   ├── 第一步：Counterpoint/IDC/Omdia 出货预测报告（摘要免费）
│   ├── 第二步：供应商量产出货公告（如 BOE/CSOT 面板量产时间）
│   ├── 第三步：标准组织路线图（USB-IF/Wi-Fi 联盟/JEDEC）
│   ├── 第四步：Gartner Hype Cycle / TRL 定位
│   └── 第五步：供应链扩产新闻（如"XX 厂商建新产线"）
│
├── "这个参数是真的吗？"（事实核查型）
│   ├── 第一步：官方规格书/官网 → A 级源确认
│   ├── 第二步：认证数据库交叉验证（FCC + CQC + BT SIG）
│   ├── 第三步：拆解报告独立验证（iFixit/eWiseTech）
│   └── 第四步：如果 3 步都无法确认 → 标"D 级待证实"入 watchlist
│
└── "我们应该跟哪个方向？"（决策支持型）
    ├── 第一步：跑第五部分的二维初筛（成熟度×匹配度）
    ├── 第二步：三维打分（技术壁垒/业务价值/可行性/紧迫性）
    ├── 第三步：专利修正（我方布局 vs 竞品布局）
    └── 输出：优先级排序 + 推荐路线 + 资源需求
```

### 4.2 搜索结果为空时的调整策略

```
搜索结果为空 / 太少 → 逐级放宽：
1. 精确匹配失败 → 去掉引号，换近义词（teardown → disassembly → breakdown）
2. 英文搜不到 → 切中文/韩文/日文
3. 官网没有 → 找供应链新闻/财报电话会议记录（Seeking Alpha, 投资者关系页）
4. 新闻没有 → 找大学/研究所论文（arXiv, Google Scholar）
5. 论文没有 → 找标准文档（USB-IF, JEDEC, MIPI 规范）
6. 标准没有 → 该技术可能还在实验室阶段，确认 TRL 级别

搜索结果太多/太杂 → 逐级收紧：
1. 加 site: 限定权威源
2. 加 filetype:pdf 只看正式文档
3. 加 after:YYYY-MM-DD 限定时效
4. 加 -keyword -keyword 排除噪音词
5. 切到 Google Scholar/Patents 专搜学术/专利维度
```

## 五、信息存储与检索系统设计

### 5.1 问题：为什么原始文档的"情报条目"需要系统支撑

原始文档定义了 14 个字段的情报条目模板，但没指定存储和检索方案。以每天 30 条、每月 600 条、半年 3000+ 条的速度，纯 Markdown 文件靠 `grep` 很快就会失控。

### 5.2 推荐方案：飞书多维表格（Base）

利用已有的飞书生态（你的 lark-base Skill），建一个**情报采集表**，字段映射如下：

| 原始模板字段 | 飞书字段类型 | 说明 |
|-------------|------------|------|
| 编号 | 自动编号 | 自动生成 |
| 领域 | 单选（芯片/显示/电池/散热...） | 下拉菜单 |
| 信号类型 | 多选（技术趋势/行业风向/材料工艺/预认证/标准/专利/竞品） | 七维标签 |
| 信源等级 | 单选（A/B/C/D/E/F） | 带颜色标记 |
| 置信度 | 数字（1–5） | 星星评分 |
| 采集时间 | 日期 | 自动记录 |
| 有效窗口 | 公式字段 | 采集时间 + 窗口天数自动计算超期 |
| 状态 | 单选（传闻/待证实/已确认/已过期） | 含 workflow 自动流转 |
| 影响方向 | 单选（利好/利空/中性） | 图标标记 |
| 关联厂商 | 文本/关联记录 | 支持筛选 |
| 印证源数 | 数字 | 手动/公式 |

## 八、信源动机分析框架

### 8.1 核心问题

原始文档的信源分级 A–F 只从"权威性"维度判断。但实战中，同等权威性的消息，因发布者动机不同，可信度和预判价值差异极大：

| 信号类型 | 常见发布者 | 可能的动机 | 对平板硬件岗的实际影响 |
|---------|-----------|-----------|----------------------|
| "苹果下一代 iPad 将采用 X 面板" | 供应链媒体/分析师 | 面板厂炒作股价、争取订单 | 可能是某面板厂在竞标，不一定中标 |
| "XX 技术取得突破" | 供应商官网/新闻稿 | 拉升估值、吸引客户 | 需区分"实验室突破"和"具备量产条件" |
| "XX 公司将量产某器件" | 产业新闻 | 供应商在向整机厂释放产能信号 | 追踪 3 个月后是否真有产线投产新闻 |
| 认证数据库新条目 | 整机厂(强制) | 法规强制，无商业动机 | **最可信**，但只证明"会上市"，不证明"会热卖" |
| 专利公告 | 整机厂 | 防御性布局/进攻性占位/技术秀 | **真的但不一定商用**，需结合产品线判断 |
| 分析师下调出货预测 | 分析机构 | 可能被做空机构影响 | 交叉验证至少 2 家机构的预测方向 |
| 拆解报告 | 媒体/自媒体 | 流量 + 专业声誉 | 拆解结果是物理事实（可信），但 BOM 估价仅供参考 |
| 论坛/社区用户抱怨 | 真实用户 | 问题驱动 | **挖掘隐藏需求的最佳源**，注意样本偏差 |

### 8.2 动机分析速查 SOP

```
拿到一条信号 → 三问：

1. 谁发布的？
   ├── 官方 → 跳过，直接采信
   ├── 媒体 → 进第二问
   └── 匿名/爆料 → 直接标记 E 级，进 watchlist

2. 为什么在这个时间发布？
   ├── 财报前 → 可能影响股价
   ├── 新品发布前 → 预热/探风
   ├── 产线投产公告 → 真实的量产信号
   ├── 行业展会期间 → 集中宣传
   └── 无特殊时间 → 常规消息

3. 谁受益？
   ├── 供应链某方 → 可能是竞争性放风，信一半
   ├── 整机厂 → 营销策略，规格可信但营销话术存疑
   ├── 第三方（拆解/评测） → 相对客观
   └── 无法判断 → 标"待证实"，等第二条独立源
```

### 8.3 典型陷阱信号识别

| 陷阱类型 | 特征 | 应对 |
|---------|------|------|
| **实验室参数当成量产** | "实现""展示""Demo"但无量产日期 | 标 D 级，等工厂产线新闻印证 |
| **供应商 Demo 当成客户采用** | "XX 面板厂推出 Y 技术"但未公布客户 | 查整机厂是否宣布采用 |
| **专利申请当成产品功能** | 专利中的功能 ≠ 下代产品一定有 | 需看有无模具/认证信号配套 |
| **小批量 = 大规模** | "XX 开始出货"但未提规模 | 查产能/产值数据交叉验证 |
| **单一分析师预测** | 仅 1 个分析师/1 家机构的判断 | 等第二家独立机构同期预测 |
| **旧闻翻新** | 旧消息改标题重发 | 检查原始日期，超 7 天标"旧闻" |
